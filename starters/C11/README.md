# C11 starter：4 比特量子核的乳腺癌分群稳定性

[题面](../../problems/extensions/C11/PROBLEM.md) · [现有参照](../../problems/extensions/C11/REFERENCE.md) · 背景：量子机器学习 · 笔记本约 30 秒

## 这道题在问什么

METABRIC 是一个约 2000 名乳腺癌患者的基因表达和拷贝数数据集。作者先用 UMAP 把它压缩到 4 维，再做聚类，希望得到有临床意义的亚型。题目问的是：把「样本之间有多像」换成量子核来度量，分群会不会更好，至少更稳定？

4 维数据正好对应 4 个量子比特，量子核只需要 16 维态矢，笔记本上算得很快，所以是很好的第一题。

## 脚本做了什么

```bash
python starters/C11/run.py
```

1. **取输入**：从作者仓库的固定 commit 下载 1980×4 的 UMAP 坐标，校验 SHA-256。只用四个坐标，不读取任何生物学标签。
2. **切数据**：固定随机种子分成开发集 660 行和评价集 1320 行。标准化参数和 RBF 带宽只用开发集估计。
3. **度量「稳定」**：每组抽 128 个共同样本（anchor），A、B 两侧再各配 128 个不同的样本。两侧分别聚成 10 类，然后看 128 个共同样本在两次聚类里的分法一致不一致，用 AMI（调整互信息）衡量。1 表示完全一致，0 表示和随机分组差不多。
4. **三种核**：
   - **量子核**：每个样本 x 编码成 4 比特态 |φ(x)⟩，线路为两层「RY(αx_q)，再对相邻比特做 RZZ(αx_q x_{q+1})」，核取 K(x,y) = |⟨φ(x)|φ(y)⟩|²；
   - **RBF 核**：K = exp(−‖x−y‖²/带宽)；
   - **线性核**：K = x·y。
5. **聚类**：取核矩阵最大的 10 个正本征向量作特征，再做 kmeans。
6. **公平比较**：先在 8 组开发数据上为量子核选 α、为 RBF 选带宽，锁定后在 24 组评价数据上报告平均 AMI。

加 `--shots` 会再模拟真实测量：每个核元素用 8192 次测量估计（3 次重复），并给出「量子 − RBF」的 bootstrap 95% 区间。

## 怎么读输出

```text
评价集 24 组平均 AMI：
  quantum  0.710777
  rbf      0.735342
  linear   0.704392
```

在这个设定下 RBF 最稳定，量子核与线性核差不多。加 `--shots` 后，量子比 RBF 低 0.028，95% 区间 [−0.057, 0.0005] 含零：既不能说量子更好，也不能说它显著更差。这是一个有边界的负结果，和现有参照逐位一致。

注意：稳定不等于正确。分群可以稳定地错，这里没有验证分出来的群是否对应真实的生物亚型。

## 下一步

1. **换编码。** 作者论文用的是 H + RZ + ZZ 的特征映射，本 starter 用 RY + RZZ。实现作者的映射，或者试试更多层、可训练的 α，看 AMI 怎么变。
2. **比较带宽更公平。** 量子核的 α 也是一种带宽。把 α 和 RBF 带宽都扫得更细，画出 AMI 随带宽的曲线，看两者的最好结果差多少。
3. **看核矩阵的结构。** 量子核和 RBF 核在这批数据上到底有多不同？计算核对齐度（kernel alignment）和有效维数，解释为什么它们的分群差不多。
4. **用上标签。** 数据里有 IntClust 亚型标签（`IntClustMemb` 列），starter 刻意没读。用它评价分群和亚型的一致性，回答「稳定的分群是否正确」。
5. **真实线路。** 用 Qiskit 把特征映射写成线路，用 compute–uncompute 测 |⟨φ(x)|φ(y)⟩|²，和态矢结果对一对；有余力可以加噪声模型。
