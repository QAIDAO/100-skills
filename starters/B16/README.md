# B16 starter：前药断键体系的两比特 VQE

[题面](../../problems/biomedicine/B16/PROBLEM.md) · [现有参照](../../problems/biomedicine/B16/REFERENCE.md) · 背景：量子化学 · 笔记本约 40 秒

## 这道题在问什么

β-拉帕醌前药在体内要断开一根 C–C 键才能释放药物。断键反应的能垒决定前药能不能在合适的时间和地点被激活。题目希望用「经典算大部分、量子算最难的一小块电子关联」的分工，估计这一步的反应自由能和活化自由能。

最难的那一小块，就是断键时 HOMO 和 LUMO 两个轨道上的两个电子，记作 CAS(2e,2o)。它小到只需要 2 个量子比特，所以是很好的第一题。

## 脚本做了什么

```bash
python starters/B16/run.py
```

1. **取输入**：从作者公开仓库的固定 commit 下载 `qc.py`，校验 SHA-256，取出 H₂O 和产物 5 的坐标。
2. **经典端**：真空 RHF/6-311G(d,p)，再做 CAS(2e,2o) 的精确对角化（CASCI）。这是这一小块的精确答案。
3. **写成量子比特**：两个电子各占 HOMO 或 LUMO，共 4 种组合，正好是 2 个量子比特的 4 个基态。第 0 比特记 α 电子在哪个轨道，第 1 比特记 β 电子。
4. **量子端**：线路 RY⊗RY → CX → RY⊗RY，4 个参数，在态矢模拟器上用 BFGS 优化能量（VQE）。
5. **对照**：VQE 能量应等于 CASCI 能量，两者再与参照报告里的数字比较。

加 `--all` 会再算产物 6、反应物 4 和过渡态 TS，并给出电子能垒 E(TS) − E(4)。这三个分子大（420–630 个基函数），每个要数十分钟到数小时。

## 怎么读输出

```text
物种             RHF/Ha           CASCI/Ha   VQE−CASCI/Ha     耗时/s
 H2O     -76.0450476154     -76.0451281250       3.13e-13      5.5
   5    -343.4685698209    -343.4792526925       1.65e-12     28.2
```

- **CASCI − RHF** 是这两个电子的关联能。H₂O 只有 0.08 mHa，产物 5 有 10.7 mHa：5 的电子结构更「多参考」，HOMO–LUMO 混合得更多。
- **VQE − CASCI** 在 10⁻¹² 量级：在没有噪声、能直接读态矢的条件下，这条 4 参数线路足以精确表示 CAS(2e,2o) 的基态。
- 最后的 ✓ 表示和参照数字一致。

## 下一步

挑一个做，半天到几天，结果不论好坏都可以提交：

1. **有限测量。** 真实设备只能有限次测量。能量要测多少次才能达到化学精度（1.6 mHa）？[入门示例解法](../../solutions/B16/qaidao-vqe-shot-budget/SOLUTION.md) 已经做了等分 shots 的版本，可以试着按 Pauli 系数和方差分配 shots，看能省多少。
2. **扩大活性空间。** 换成 CAS(4e,4o)（8 个自旋轨道）。参照显示 5 和 6 的能量会再变 10–15 mHa。用 UCCSD 或硬件高效线路做 VQE，比较参数数、线路深度和精度。
3. **加溶剂。** 题面要的是水溶液中的自由能。仿照作者 `qc.py` 加 ddCOSMO，看溶剂对 CAS(2e,2o) 能量的影响有多大。
4. **加噪声。** 用 Qiskit Aer 的去极化噪声模型跑同一条线路，看噪声下 VQE 的能量偏差，以及零噪声外推能修回多少。
5. **跑完 `--all`。** 在工作站上算出 4 和 TS，报告 CAS(2e,2o) 下的电子能垒，与原文和 DFT 比较。
