# 从解法沉淀 skill

skill 是一份让 Agent（或研究者）能重复解决同类问题的说明：什么时候用、需要什么输入、怎么做、怎么验证、哪里会失败。这里的 skill 只从社区**已采纳**的解法中提炼，不凭空编写。

v0.1.0 发布时还没有 skill，这份文档定下规则。

## 沉淀条件

同一方法族（`solution.json` 的 `method.family`）满足以下全部条件时，可以提出沉淀：

1. 至少 2 份已采纳的解法，其中至少 1 份经过独立复现；
2. 覆盖至少 2 道题，或者同一道题上至少 2 组互相独立的输入；
3. 已知的失败条件与适用边界有记录：负结果和局限同样是沉淀的原料；
4. 提炼出的步骤能在一份未参与提炼的输入上复跑通过。

由任何人开 issue 提出沉淀，列出来源解法；维护者确认条件后再开 PR。

## skill 结构

```text
skills/<skill 名>/
  SKILL.md        # frontmatter：name、description、allowed-tools；正文见下
  scripts/        # 可选：从来源解法整理出的可执行代码
  examples/       # 可选：来源解法的小型输入与期望输出
```

`SKILL.md` 正文至少包含：何时使用、输入要求、步骤、验证方法、失败条件，以及来源解法列表。

## 署名与许可

- `SKILL.md` 中列出全部来源解法及其作者，并链接到对应目录。
- 文字部分采用 CC BY 4.0，代码部分采用 Apache-2.0；来源解法使用 MIT 或 BSD-3-Clause 时，保留其原许可声明。
