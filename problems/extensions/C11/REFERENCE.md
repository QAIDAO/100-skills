# C11：公开 METABRIC 分群稳定性实验（R53）

**这轮量子核没有达到预设稳定性收益门。** 在开发集选出的 RBF 对照下，8192 shots 量子核的平均 AMI 差为 **-0.028263**，条件 bootstrap 95% 区间为 **[-0.057293, 0.000506]**。区间包含零；不能宣称量子核优于 RBF，也不能据此宣布 RBF 具有总体统计优势。预先约定的下端大于0.05门失败，失败保留，不换参数重跑。

本限定任务推荐经典 RBF。完整4比特态只有16维，经典算重叠本身很便宜；实际硬件运行没有实用收益证据。这里的推荐只针对本次候选和固定表示，不是所有量子核的全局最优性结论。

## 数据、方案与比较条件

作者公开CSV包含1980行四维UMAP坐标，SHA256 `71a930deff2d3d4e968b01487b9d9385b9747fed5f8ad05cf3b96b19dab2c91e`。原有记录指定作者commit `f08d20382e35f63509aae5249d8ec879ceaaa185`；本轮确认本地CSV身份，没有重新认证远端Git对象。只用Component_1至4，不使用IntClustMemb标签值。原UMAP由全体数据拟合，因此以下是固定压缩表示上的转导实验。

固定随机dev660/eval1320互斥划分，只在dev拟合标准化均值/标准差和非零平方距离中位数。开发8组、评价24组；每组独立抽128共同anchor及双方各128独有行，每侧256。所有组分别重抽anchor，组间患者允许复用。每组内双方只有anchor相交。

量子映射是4比特两次数据重上传：每层Ry(αx)，随后邻接RZZ(αx_ix_j)；K(x,y)=|〈φ(x)|φ(y)〉|²。开发量子候选α=.2/1/2，RBF候选倍率=.25/1/4，另加linear。统一取核最大的10个正本征模乘平方根特征值，k=10、十次初始化kmeans；这里明确定义为正谱特征加kmeans，不自动等同归一化图Laplacian谱聚类，也不标作者聚类实现复现。linear可以只有4个有效维度，不把10个簇当10个物理维度。

按8组开发平均AMI选量子/RBF参数，随后在RBF与linear中选最强经典family，精确平局用既定顺序。评价阶段参数和family锁定。AMI分母采用论文Eq13的max(H_U,H_V)−E[MI]，保留负分。全部选定分群有10个非空簇、共同anchor至少两类；选定Lloyd过程最多35轮，无选定解达到100轮上限。

每个评价量子核对上三角非对角元素分别以2048/8192次binomial抽样，各三重复，A/B使用不同随机流；对角1为解析已知。保存所有uint16计数、原始负谱和特征。负本征值不冒称PSD：聚类明确只使用最大的正本征模。每组8192三次AMI平均减锁定经典AMI，得到24差值；对整个组重抽10000次，中央95%分位数区间。置信区间仅条件于固定UMAP、split、开发选择及指定抽样机制，不包含开发选择不确定性，不是患者总体或临床效益置信区间。

## 独立验证与成本

生产4996项实现检查通过；独立18186项检查通过。独立路线使用完整16维Kronecker态与投影算符Hilbert–Schmidt内积重建96套态和对应核，审计全部256个理想核、288个有限测量核、272项AMI及10000次bootstrap。AMI期望项用整数comb超几何概率及fsum，区别于生产lgamma计算。没有重跑完整kmeans优化；检查保存特征、全谱、最近中心、目标值、初始化seed及保存的最小目标选择。

固定8对原CSV行(0,1)至(14,15)另做真实理想线路资格：先U(x)再U(y)逆，分解到每对16RY+12RZ+24CX，比较测得0000的概率。仅这8对执行基础门线路验证；其余核由完整态重叠计算，不宣称已逐核逐shot执行基础门线路，无routing、噪声模型或QPU。

共544次谱分解/聚类，288个有限测量核，**48,129,638,400 Bernoulli等效测量次数**。实际用聚合binomial计数模拟，并没有执行481亿次电路。单次compute-uncompute需一次电路初始化、两次特征映射调用；对角没有shots。主生产态准备CPU约0.092秒、理想重叠约0.049秒，经典核约0.035秒，聚类约12.48秒；这些包含不同候选/调用数，不能当同总成本加速比。

生产、审计及首次启动失败合计封存成本 **63.33 CPU秒 / 54.30 累计wall秒**，最高RSS **214941696字节**，scratch0。生产预算600CPU/900wall/2GiB/256MiB，审计120CPU/240wall/1GiB/32MiB，均通过。成本包括各自监控；文献检索、源码准备和绘图不在科学作业计时内。资源监控0.05秒采样并保留瞬时漏采边界。
