# C15：二维温度场暴露训练、读出与网格三种误差

新增4×4与8×8内点的二维实验已完成并独立核验，**完整温度场的预定精度目标未通过**。单位正方形右边界温度1、其它三边0，常导热、5点有限差分；量子线路分别为4和6比特、5层RY/CX。每网格3固定训练seed，按VQLS目标选优；精确参考只用于评分。

量子读出只使用计算基采样计数，以vhat=√(counts/shots)恢复正幅值，再由s=((A vhat)·b)/||A vhat||²恢复绝对尺度，最终温度为s vhat。这里A和b已知，精确温度与其尺度不进入估计器。旧1D代码也使用该方法；本轮补的是二维与联合验收，并非首次实现尺度恢复。训练态符号逐项独立验证，未仅凭PDE解正性替代线路资格。

完整原始结果包括6个训练候选、全部参数与态、每个4096／16384／65536预算的200组counts和温度场。两网格各自采用单侧97.5% Clopper–Pearson下界，对最高预算用Bonferroni控制两网格联合置信；两者0次成功均未通过。图中均值仅帮助观察趋势，不代替逐次联合门。

经典基线使用稀疏直接法、独立CG及稳定计算的连续Fourier级数（128／256项互检）。4×4网格自身离散误差已超门，完美量子求解也不能消除；8×8离散误差通过，但当前5层线路与训练预算未求得合格近似。没有证据把后者单独归因于优化器、表达能力或局部极值，需新的受控比较才能区分。

存在一个必须保留的协议偏差：我将L-BFGS-B的maxfun=12000写成硬限，但数值梯度会完成整批评估，三个8×8seed实际各12028次。此次每seed严格12000门未满足，不能因CPU限额通过而补签。结果作为失败与实现边界证据保留，不重跑、不只挑成功seed。

本次生产19.43 CPU秒／17.25 wall秒、峰RSS119046144字节；独立核验另0.410 CPU秒，53项检查通过。核验通过表示负结果、保存数组及限额偏差可信，不代表原科学目标成功。三个预算累计34406400个状态制备为硬件等效抽样账，本机由状态向量生成聚合multinomial计数；训练也不是有限shot训练。经典单次求解时间与该账不能直接形成QPU速度比。

当前优先推荐仍为稀疏经典求解完整温度场。停止本固定VQLS协议；后续若评估量子方法，应先明确更合适的可测输出或有根据的预条件／结构化线路，并真实计入训练与读出成本。缺少2D的旧状态已经补齐，但复杂材料、变导热、噪声训练及端到端优势仍未验证。
