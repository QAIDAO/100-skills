# C08：原 biotin 适配体的完整18茎量子子实验

本轮取得原 Table A/D 的 biotin-PK-AN69.1（PKB00176）真实33nt序列及11对参考碱基配对，完成18茎完整QUBO、80态强经典基准和实际18比特硬约束QAOA。原生完整p=4线路的Qiskit状态向量与80态模拟一致，误差1.36e-13；没有新增QPU调用。

两个结果需要分开：最低目标分−117确实能找到，但其13对配对包含两对参考中不存在的配对，precision=11/13、recall=1、F1=11/12。真实11对结构也在同一80态可行空间中，分数却为−41。目标函数偏爱错误扩展，属于模型偏差，不能归咎于量子比特表示不足。QAOA的冻结单shot/期望分数门失败，但全部18个p=4有限读取批次均找到−117；不能把单shot门失败改称“有限预算找不到最优”。原RNA应用仍未完成。

## 冻结模型与不同协议

按公开代码的小集参数min_stem_len=4、min_loop_len=3生成所有18个候选茎，保留完整与子茎。loop参数按作者字面边界`(j-k)-(i+k)>=3`执行，意味着末对间至少2个未配对碱基；没有静默修正为另一种“3未配对碱基”定义。没有借参考结构筛选候选。μ为所有候选的最大长度7。

每个茎占据为一个比特。原分数的线性项为`10(k_i-μ)^2-k_i²`，通常二次项为`-2k_i k_j`；假结减半为`-k_i k_j`，共享任一核苷酸则覆盖为500000罚项。全2^18配置的唯一最低分为−117，不可行配置最低499821；独立负项总和界证明任何重叠态分数至少498441，因而原soft-penalty模型的全局最优属于80个不重叠态。原h/J、所有位点、冲突图和SHA256均在运行前冻结。

新量子协议采用硬约束mixer，与作者D-Wave软惩罚/hybrid协议不同。初态为18位空态，每层先实施原可行分数的cost相位，再按茎索引依次实施RX(−2β)，仅在该茎所有冲突位为空时旋转；茎数可变，并非固定粒子数问题。80态空间完整保留，不减少18个原自由度。相位归一化采用可行分数最大绝对值132，不使用生物真值。优化只访问QUBO分数，参考配对仅进入事后质量计算。

p=1/2/4、固定优化seed71/72/73，BFGS最多120迭代。初始空态的cost分数是0，因此每种深度的第一γ完全无效，p=1只有一个有效β。这个初始化和共享β限制属于本候选架构；p=1结果不能解释为QAOA普遍局限。三次p=4退出均为precision loss，p=1/2也保留退出状态；没有重调当前Ansatz或种子。

冻结门包括：状态一致性≤1e-10，可行读取≥.999；全部p=4种子单shot基态概率≥.5、归一化期望分超额≤.01；所有精确目标基态的precision/recall/F1均≥.95。以下保持原门，未因有限读取成功或已看真值放宽。

## 最优分数与真实结构

唯一目标基态使用茎[3,10]，mask1032，13对中11对正确、2对额外，额外配对为(2,21)/(9,33)。它仍有假结且没有核苷酸占据冲突，证明“物理可行”与“参考正确”不是同一门。其precision=0.846153846、recall=1、F1=0.916666667，physical-model门失败。

真实参考结构mask8224、茎[5,13]就在同一候选集合中，score−41，precision/recall/F1均1；目标最低分−117比真值分数低76个无量纲score单位。不能将这些score解释为实验自由能或kcal/mol。独立窗口式茎构造、可行掩码枚举及`10Σ(k−μ)²−(Σk)²+Σcrossing k_i k_j`公式重算通过。父级另以完整2^18整数递推和真实核苷酸占位判定核验，结果一致。

强经典参照为完整80态精确最优（全2^18验证同值），不只使用SA/uniform。额外控制是uniform80及可行flip-SA64sweeps，分别各6个同read-budget批次。两种控制的全部批次也找到−117；uniform每shot基态概率1/80，而SA的8192读取hit比例约9.59%–22.99%。SA批内各轨迹共享每sweep提议顺序，独立接受随机数；只做描述性比较，没有将批内样本误称为独立试验并计算虚假的置信度。找到最低分的同时，两类控制同样得到错误扩展的最低分结构。这里没有量子优势主张。

## 实际线路、成本与验证边界

最低期望分的p=4 seed72线路，完整18比特状态向量两条路径都核对：独立全2^18受控门作用与80态幅度误差2.78e-17，泄漏概率0；Qiskit原生全线路幅度误差1.36e-13（忽略全局相位），符合冻结门。无需超时或只验证局部线路。受控RX按实际冲突邻居展开，多控制条件并未算成一个廉价CX。

该实际原生电路为18 logical qubits、0 ancilla、10344 CX、12196 U、深度17887，QPY保存可复查。此为u/cx无硬件路由编译，未加噪声、实际嵌入、校准或纠错。对这条线路，1024/8192最终读取对应约1.06千万/8.47千万次CX调用的理想预算；其它设置未逐条编译，不能给所有优化电路套同一门数。

9个量子参数优化共3591次**精确状态向量期望分**评估，最终量子读取共248832shots；uniform/SA控制另55296，合计304128。没有执行有限shot的优化能量估计或硬件噪声优化，其额外shots/执行成本未知。模拟器最终multinomial读数不能算新增硬件运行。

主作业单CPU约32.91秒，全2^18强经典基准约0.11秒；后者包含初始化/数据处理，不是80态枚举的专门计时。原生合成过程出现numpy determinant运行警告，原stderr完整保留；未压制警告，最终矩阵有限、归一化和全线路幅度核对通过。未测峰值RSS。所有冻结输入/driver哈希、66组量子与控制读取的分数/hits/F1、独立随机流和谱最低分复查通过。
