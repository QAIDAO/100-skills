### 原案例说明

### M27 · 卤化物钙钛矿：自陷激子与缺陷的局域化和非辐射通道

> 第三轮补题（2026-10-14）：仅文献整理的开放题，本项目没有对本题执行任何计算。来自原问题单 M27。

#### 研发决策与价值

判断自陷激子的发光与损耗由哪些局域结构决定，从而指导宽谱白光发射体与低损耗光伏材料的组分设计。

#### 模型与可观测量

- 研究体系：Cs₄SnBr₆、Cs₂AgInCl₆、Cs₂AgBiBr₆ 等无铅卤化物钙钛矿中的自陷激子、极化子与缺陷陷阱态
- 可观测量：自陷激子局域化能与发光斯托克斯位移、陷阱态能级、非辐射复合通道
- 规模：自陷激子需大超胞与晶格弛豫；可交给量子求解的是嵌入后的局域难核

#### 量子—经典工作流（建议，未运行）

对局域的激子—晶格难核做嵌入，用多态子空间或 QPE 求局域态，必要时把电子与核坐标联合编码（提案）

#### 强经典基线

含激发态几何弛豫的杂化 TDDFT；GW/BSE 加密度泛函微扰的激子极化子方法；量子缺陷嵌入；非绝热分子动力学

#### 已有文献与证据边界

经典侧：WEST 代码的杂化 TDDFT 研究了 Cs₄SnBr₆ 与 Cs₂AgInCl₆ 的自陷激子；另有研究讨论双钙钛矿中自陷激子的量子干涉与光学调控。2026-10-14 检索未见针对该具体体系的量子计算研究（检索不穷尽）。

局限：不能把所有钙钛矿性质预测都列为量子任务；量子只针对经典嵌入与 GW/BSE 难以描述的局域难核。

#### 与已有题目的区别

最接近的现有题目：M08、M09、M16。对象是钙钛矿的激子—晶格自陷；M08、M09 是色心多重态，M16 是 hBN 缺陷发光。

#### 可执行试点（建议，未运行）

先选一个已有 TDDFT 与 GW/BSE 结果的体系，比较两者对自陷激子局域化能的分歧，确认是否存在需要更高精度的局域核心。

#### 文献与读取范围

- R1 [The WEST code for large-scale excited-state materials simulations](https://arxiv.org/abs/2607.14025)（2026），预印本；读取范围：search_excerpt。杂化 TDDFT 加激发态几何弛豫，用于 Cs₄SnBr₆ 与 Cs₂AgInCl₆ 的自陷激子。
