# M19：完整 62 比特固定线路通过数值验收，但未显示求解收益

反应物 RC 的完整 44e31o、62 自旋轨道固定线路，已在经典计算机上以 χ32/64/128 三档 MPS 模拟。全部范数、自旋、逆向、抽样、跨 χ 和资源门通过。固定参数态能量却比 HF 高 67.6721 mHa；量子样本的单重态子空间也弱于低成本经典提案。这是完整空间线路组件完成，不是优化 VQE、原催化目标或量子优势完成。

模型沿用公开 87 原子坐标的新派生真空 H：683 AO、344 总电子，冻结核常数与完整 44e31o 活性 H 不变。只做 RC 量子线路，没有 TS/PC 量子能量。原 UUID 积分、真实环境与活性空间收敛仍缺。既有输入与诊断（本地证据，未随题库发布）

## 线路与实现

联合自旋 Givens 旋转和 onsite 双占据相位均守 N 与 S²，作用于完整 31 个四态 site，含单占开放壳层支撑，不是 paired-only。它属于 LUCJ 相关的自旋标量子族，不等同原论文完整 ansatz。[LUCJ 原论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC10583744/)

原候选同 R 的两层会严格折叠成一层，且原排序让尾部 11 轨道始终双占，已保留解析证据。生产前另冻新设计：空 site 为 1/5/8/12/15/18/22/25/29，其他 site 顺序填占据轨道；R1/R2 的 bond 交替角分别 ±0.20/±0.31，onsite 相位为 +0.20/−0.30。潜在支撑覆盖全链不代表两层覆盖全部单重态配置，也不表示化学最优。

每次制备含 44 个 HF X、120 个空间 Givens（240 个自旋 Givens）、62 个 onsite 相位。显式费米交换路由的已保存 Qiskit 编译为 1,564 CX、深度 215，全部 CX 相邻；这是指定分解的理想资源账，不是最小门数、噪声性能或真实 QPU 时间。8192 次该制备对应 12,812,288 CX 等价调用，不包括能量读出、优化、纠错和子空间求解。

MPS 使用 Nα/Nβ 分块单 site QR/LQ 规范移动和双 site SVD 截断。旧无上限 identity-SVD 会因浮点近零值使 χ4 膨胀到 25，已在独立版本修复。实际全链键维数逐门检查；截断损失含 cutoff 与 cap，原始范数不逐步归一掩盖。SZ 结构只保 Sz，所以另以数值 S² MPO 验证。[官方 block2 API](https://block2.readthedocs.io/en/latest/api/pyblock2.html)

生产 CPU 合计 414.322 秒、wall 433.184 秒；每档均在 300 CPU 秒、600 wall 秒、2.5 GiB、1 GiB 输出上限内。独立读回审计另消耗 χ64 81.252 秒和 χ128 132.799 秒，不能遗漏；χ32 审计最终 JSON 写出失败，已通过断言的误差界保留，但其精确审计数值和 CPU 未保存。没有为补这个记录重跑传播。

## 同 H 经典基线与样本提案

全部 31 活性轨道的 RCCSD 使用同一 H，仅在占据/空轨道各自内部半规范化，不新做 SCF。三点均在 17/20/21 次迭代收敛，最终幅度更新残差 <4.58e−8；三点 CPU 最后采样合计约 5.04 秒。RCCSD 非变分，不是精确真值或能量下界；T1 数值按报告显式公式，不套不同规范的经验阈值。[PySCF CC 方法说明](https://pyscf.org/user/cc.html)

## 当前推荐与证据边界

本模型优先采用低成本经典相关计算，并解决活性空间、自旋竞争和环境误差。若推进量子候选，必须另冻真正变分参数、目标态质量和完整优化成本，至少与本轮一阶提案、RCCSD及更充分收敛的变分经典基线比较。双因子化 QPE 是容错候选，仍需初态重叠、受控演化和总资源证据。单纯重复固定线路、增加 shots 或比较均匀态不能填补已观察到的收益缺口。

历史失败均保留：原候选折叠、非规范截断、identity-SVD rank 膨胀、监控权限失败后安全终止、小 fixture 的截断精度失败、早期 DMRG 未收敛及独立 χ32 审计序列化失败。RCCSD 的历史 delivery-manifest 仍含旧 REPORT hash；最终 final-output-manifest 与当前最终报告相符，独立审计已将这一区别记录，未静默改写历史。

完整证据入口为本目录 results.json / manifest.json，以及 materials 下 m19-full31o-circuit-v1、m19-rccsd-baseline-v1、m19-rccsd-stationary-v2、m19-sampled-subspace-v1、m19-circuit-structure-audit。原应用目标保持未完成。
