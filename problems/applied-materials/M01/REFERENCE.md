# 原完整模型成对 UCJ：Slater 求积模拟结果（R151）

本轮在公开的 II34e26o／TS38e29o 原完整轨道模型上，完成两个固定 rank1 成对 UCJ 线路的 4／8／12 节点数值评价。两端各保留两个 J 相位、所有轨道、完整 Hamiltonian 和末端 singles 旋转。12 节点较同模型 RHF 降低约 50.99／58.13 mEh，仍高于 CCSD 和 M256。参数未优化，未证明最优或量子优势。

这是新的有限模型数值实验，不是原论文逐点复现。总 Goal 仍为 active：84 项任务、64 项历史或当前量子组件、0 项原应用完成。

## 方法为何适用于这两个线路

R149 每个外因子产生两个相位；第一外因子的 Jaa=Jab=λddᵀ，使相位可写成 exp(iλN_d²/2)。标准正态 Hubbard–Stratonovich 积分把它展开为非酉 Gaussian 轨道操作的加权和，保留两个相位的原顺序。每层 K 节点给 K² 个闭壳层 Slater 项和 K⁴ 个有序 bra/ket 对。QR 的 det(R)² 复系数完整保留。完整 Hamiltonian 的矩阵元以 adjugate 多项式评价，奇异重叠不丢弃；ECORE 与 active 能先分开求和再归一化。

高斯求积的多项式精确性与余项依据见 [NIST DLMF §3.5(v)](https://dlmf.nist.gov/3.5#v)，参数语义见 [ffsim 官方说明](https://qiskit-community.github.io/ffsim/explanations/lucj.html)。特定闭壳层公式与误差界由本轮独立完整 36 维测试核验，不能仅凭文献链接视为实现已正确。详见 方法研究（本地证据，未随题库发布）。

R150 同一候选的 MPS 表示曾在范数门失败；原失败已封存，本轮改变表示后范数保持在 1 附近。该对照支持用 Gaussian／Slater 表示模拟当前 rank1 候选，不证明任意更深线路都可高效模拟。完整原 t2 外秩对应 306／380 层，本轮只有两层。
