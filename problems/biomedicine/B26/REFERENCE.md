# B26：公开 OEC 自旋模型、经典谱与原生门检验

本修订补齐正式补充材料 Table 1 的两种候选模型，并将旧的理想双自旋传播推进到显式原生门检验。原始应用目标仍未完成：量子自旋分辨能谱、有限测量及催化物理结论须分别验收。

## 模型身份与优先方案

[正式论文](https://www.nature.com/articles/s41567-024-02738-z)的[官方补充材料](https://media.springernature.com/original/springer-static/esm/art%3A10.1038%2Fs41567-024-02738-z/MediaObjects/41567_2024_2738_MOESM1_ESM.pdf)给出 S2H-1b 和 S2H-2b 的六个交换参数。原页已渲染并逐项核对；作者 model1 与 1b 一致。旧 model0 的参数集合与 2b 不同，不能用文件序号替代结构身份。

采用 `H = −2 Σ Jᵢⱼ Sᵢ·Sⱼ`，四站点 `2S=(3,3,3,4)`，物理空间维数 320。符号约定由作者完整矩阵核对支撑。按 `J12,J13,J14,J23,J24,J34` 排列，1b 参数为 `(30.5,12.9,4.5,36.5,1.3,−7.3)` cm⁻¹，2b 为 `(32.6,11.7,4.0,37.3,1.5,−2.6)` cm⁻¹。

当前优先用 SU(2) 对称性分块的经典精确解建立参考，再评估守对称性的量子谱协议。320 维经典计算十分廉价，量子方案的价值首先是方法验证，当前没有速度或精度优势证据。二进制局域编码需 9 比特；作者 13 比特簇编码是另一种实现，不能混报资源。通用 QSD 门分解可给出明确实现成本，但不保证最少门数；针对角动量耦合结构的分解是后续比较对象。

## 原生门实验的固定问题

先检验 1b 的 Python 站点 `[2,3]`，即补充材料的一基索引 `J34=−7.3 cm⁻¹`。半步时间 0.00025 ps，目标为 20 维物理酉算符嵌入 5 比特空间。物理索引 `a×5+b` 映射为二进制索引 `(a<<3)|b`；12 个无效编码应保持恒等。

Qiskit 1.4.5 的 QSD、译码设置和实际源码散列均冻结。先生成 U/CX，再以 `RZ(λ), RY(θ), RZ(φ)` 展开 U 门，并累加全局相位 `(φ+λ)/2`。保留零角门，门深度按实际 primitive 序列重算。验收要求全部 32 列相位敏感幅度误差及逆线路误差≤10⁻¹⁰，范数及无效编码泄漏≤10⁻¹²。

旧 v4 因 SDK 的直接基变换接口失败退出，日志和成本保留。v4.1 只修复接口，科学门槛不变；小型人工线路验证独立于真实 5 比特试验。人工 fixture 首次 CPU 未观测，不能声称其累计成本完整；两次已观测部分合计 0.876383 CPU 秒。JSON 辅助检查的过严逐位相等断言失败已保留，后续字典逐字段往返相等和数值容差检查通过。

真实原生门结果、独立终审与成本以本目录 `results.json` 及下方终态记录为准。未通过最小 pair 的科学门时，不启动条件性的其余 pair 或 9 比特单周期。

## 保留的旧量子组件与边界

旧 320 维完整物理空间 Strang 传播在 0–1 ps、51 个时间点比较，最细步长最大不保真度 4.54945×10⁻¹⁰，总 Sz 漂移 2.24099×10⁻¹²。该结果采用理想双自旋局域酉，不等于完整原生门传播。旧 survival 是复振幅的模平方，不能据此报告绝对能量或自旋分辨谱。

没有 QPU 调用，也没有由本机 CPU 时间推断量子硬件加速。自旋有效模型求解不验证模型降阶误差、氧析出反应率或催化活性。后续谱协议必须支付初态制备、相位敏感读出、长时间演化及测量成本，并与上述经典分块参考比较。
