# B16-M02 · 同总 shots 下比较三种测量分配（v1）

- 所属题：[B16](../problems/biomedicine/B16/PROBLEM.md)
- 类型：method-comparison　状态：ready　审核角色：量子算法审核者（维护者指派）
- 前置：建议先完成或读过 [B16-M01](B16-M01.md) 与 [入门示例解法](../solutions/B16/qaidao-vqe-shot-budget/SOLUTION.md)

## 目标与范围

入门示例给每个测量基分相同的 shots。本任务在**相同总 shots** 下比较三种分配：

1. 等分（现有做法，作为基线）；
2. 按各组系数绝对值之和加权；
3. 先用一小批先导测量估计各组方差，再按方差最优分配（先导测量计入总预算）。

覆盖：H₂O 与产物 5，入门示例的固定最优参数、同一 4×4 哈密顿量和同一逐比特对易分组。
不覆盖：门噪声、读出误差、在噪声能量上的参数优化、更大的活性空间。B16 原题保持 open。

## 冻结的设置

- 输入、态与分组：与 `solutions/B16/qaidao-vqe-shot-budget/code/shot_budget.py` 完全相同，直接 import 复用，不复制改写。
- 总 shots：每个体系取 {1024, 4096, 16384, 65536} 四档，三种方法相同；方法 3 的先导测量占总预算的比例事先选定并报告。
- 重复：每档至少 2000 次独立重复，使用互不重叠的随机种子并全部报告。
- 精确值：同一哈密顿量的精确对角化（CASCI）。

## 验收

- 报告每档每种方法的 RMSE、落在化学精度（1.6 mHa）内的比例及其二项标准误、平均偏差。
- 比较结论用事先声明的检验：方法 B 比 A「更好」当且仅当 RMSE 比值的 95% 置信区间整体小于 1（自助法或解析方差均可，须说明）。
- 方法没有改进也完成本任务：如实报告即可。
- 统计判据按抽样误差给容差，不要求不同平台逐位一致。
