- 类型：reproduction　状态：ready　审核角色：量子化学审核者（维护者指派）
- 适合：第一次参与，不需要量子化学背景

## 目标与范围

在一台不是原作者的机器上，只按公开材料跑通 [starters/B16](../starters/B16/README.md) 的默认模式，核对四项能量。

覆盖：H₂O 与产物 5 的 CAS(2e,2o) CASCI 与两比特 VQE 能量。
不覆盖：4、TS 与能垒（`--all`）、溶剂效应、反应自由能。B16 原题保持 open。

## 输入

[starters/B16/inputs.json](../starters/B16/inputs.json)：作者仓库 AceMapAI/qc-drug-design 固定 commit `1f9e425` 的 `c_c_bond/qc.py`，SHA-256 `2a5504d2…69aa`，脚本自动下载并校验。只从中提取几何坐标文本，不导入执行。

## 环境与命令

Python 3.12；`starters/requirements.txt`（numpy 1.26.4、scipy 1.13.1、pyscf 2.12.1）。在仓库根目录：

```bash
python starters/B16/run.py
```

默认 CPU，不用 `--all`，不用 QPU。参考耗时：维护者 2026-11-03 在 Apple M5 笔记本的干净 uv 环境（Python 3.12.13）实测 37 秒墙钟；请记录你的实测耗时与内存。

## 验收

- 必需结果：`E_CAS2[H2O]`、`E_CAS2[5]`、`E_VQE[H2O]`、`E_VQE[5]`。
- 判据：与 [expected.json](../starters/B16/expected.json) 对应值的绝对差 ≤ 1e-6 Ha；任一项缺失或非有限数即失败（`run.py` 退出码 1）。
- 失败也是有效结果：环境装不上、数字对不上，把完整输出和环境写进记录，同样算完成本任务，并帮助我们修文档。
